# Catch the Coin Using Q-Learning

## Project Overview

This project demonstrates the implementation of the Q-Learning algorithm in a simple Catch the Coin game.

The objective is to train an intelligent agent to catch a falling coin by learning through trial and error.

## Features

- Reinforcement Learning
- Q-Learning
- Q-table
- Epsilon-Greedy Exploration
- 5000 Training Episodes
- Performance Evaluation
- Reward Graph
- Catch Rate Graph

## Technologies

- Python
- Matplotlib
- Jupyter Notebook
